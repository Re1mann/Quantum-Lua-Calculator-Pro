# ⚡ Quantum Lua Calculator Pro

> **Продвинутый консольный инженерный, графический и матричный калькулятор на языке Lua.**  

---

## 🚀 Основные особенности

- 🎨 **Киберпанк/Neon UI в терминале**: Стилизованные ANSI-рамки (rounded box), статусный HUD (угол DEG/RAD, количество переменных, длина истории), динамические таблицы.
- 🧠 **Собственный математический парсер**:
  - Токенизатор и рекурсивный синтаксический анализатор (метод восходящего приоритета операторов).
  - Поддержка неявного умножения: `2(3+4)`, `3sin(x)`, `5pi`, `2x`.
  - Постфиксные операторы: факториал `5!`, проценты `50%`, `200 * 15%`.
  - Правоассоциативное возведение в степень: `2^3^2` = $2^{(3^2)}$ = $512$.
  - Целочисленное деление `//` и остаток `%`.
- 📈 **ASCII / Unicode 2D Построитель графиков в консоли**:
  - Построение любой функции $y = f(x)$ прямо в окне консоли с координатными осями $X$ и $Y$, метками диапазонов и авто-масштабированием.
- 📐 **Модуль решения уравнений**:
  - Квадратные уравнения $ax^2 + bx + c = 0$ с подробными шагами решения через дискриминант $D$ и поддержкой комплексных корней.
  - Системы линейных уравнений 2x2 (СЛАУ) по методу Крамера ($\Delta, \Delta_x, \Delta_y$).
  - Численный поиск корней произвольного уравнения $f(x) = 0$ методом секущих.
- 💻 **Режим программиста (Bit Inspector)**:
  - 32-битная интерактивная битовая сетка (Bit Board) с цветовой подсветкой установленных битов `1` и `0`.
  - Конвертация между DEC, HEX, BIN, OCT, подсчет единичных битов (POPCNT), знаковые типы (Int8, Int16, Int32).
- 🔄 **Конвертер физических величин**:
  - Длина (м, км, мили, дюймы, футы, морские мили).
  - Масса (кг, граммы, фунты, унции, караты).
  - Температура (°C, °F, K).
  - Объем данных (байты, КБ, МБ, ГБ, ТБ, KiB, MiB, GiB).
  - Скорость, давление, время, энергия.
- 🔢 **Матричная алгебра**:
  - Сложение, вычитание, умножение матриц $A \times B$.
  - Определитель матрицы $\det(A)$ методом Гаусса для любого размера $N \times N$.
  - Обратная матрица $A^{-1}$ методом Гаусса-Жордана.
  - Транспонирование и след матрицы.
- 💾 **Память и журнал истории**:
  - Переменные: `x = 10`, `r = 5`, `S = pi * r^2`.
  - Предыдущие результаты: `ans`, `ans1`, `ans2`...
  - Экспорт журнала сессии в текстовый файл (`export`).
  - Пошаговое интерактивное меню (`menu`).

## 🚀 Запуск

### Способ 1: Через командную строку (Windows / Linux / macOS)
```powershell
lua main.lua
```

### Способ 2: В один клик на Windows
Просто дважды щелкните по файлу `run.bat` — он автоматически настроит консоль на вывод UTF-8 и запустит калькулятор.

### Способ 3: Однострочные быстрые вычисления из консоли (CLI Mode)
Калькулятор можно вызывать из терминала для быстрых расчетов и сценариев:
```powershell
lua main.lua "sin(45)^2 + cos(45)^2"
lua main.lua --plot "x^2 - 4" -4 4
lua main.lua --solve quadratic 1 -5 6
```

### Запуск тестов
```powershell
lua tests.lua
```

## 📖 Примеры команд и синтаксиса

### 1. Вычисления и функции
```text
⚡ [calc] > 2 + 2 * 2
➔ 6

⚡ [calc] > 5! + 2^3
➔ 128

⚡ [calc] > 2(3 + 4)
➔ 14

⚡ [calc] > sin(30) + cos(60)
➔ 1

⚡ [calc] > 200 * 15%
➔ 30

⚡ [calc] > gcd(48, 180)
➔ 12

⚡ [calc] > nCr(10, 3)
➔ 120
```

### 2. Переменные
```text
⚡ [calc] > r = 5
r = 5

⚡ [calc] > S = pi * r^2
S = 78.539816

⚡ [calc] > ans * 2
➔ 157.079633

⚡ [calc] > vars
(выводит таблицу сохраненных переменных)
```

### 3. Построение 2D графиков
```text
⚡ [calc] > plot sin(x) -3.14 3.14
⚡ [calc] > plot x^2 - 4 -5 5
⚡ [calc] > plot cos(x) + sin(2x) -6 6
```

### 4. Решение уравнений
```text
⚡ [calc] > solve quadratic 1 -5 6
(выводит шаги: D = 1, x₁ = 3, x₂ = 2)

⚡ [calc] > solve 2x2 2 1 5 1 -1 1
(решает систему методом Крамера: x = 2, y = 1)

⚡ [calc] > solve root x^3-2x-5 2 3
(находит корень f(x) = 0 методом секущих: x ≈ 2.094551)
```

### 5. Режим программиста и биты
```text
⚡ [calc] > base 255
(выводит 0xFF, 0o377, POPCNT = 8, 32-битную визуальную сетку)

⚡ [calc] > 0b1010 + 0x1F
➔ 41
```

### 6. Конвертация физических величин
```text
⚡ [calc] > convert 100 km to mi
➔ 62.137119 mi

⚡ [calc] > convert 36.6 C to F
➔ 97.88 F

⚡ [calc] > convert 1024 MiB to GiB
➔ 1 GiB
```

### 7. Матрицы
Введите:
```text
⚡ [calc] > matrix
```
И выберите операцию:
- Нахождение определителя $\det(A)$
- Обратная матрица $A^{-1}$
- Умножение $A \times B$
- Сложение / вычитание
- Транспонирование

## 🛠 Технические детали реализации

- **Алгоритм разбора выражений**: Применен алгоритм восходящего приоритета (*Precedence Climbing / Pratt Parsing*), позволяющий легко регулировать ассоциативность (например, степень `^` правоассоциативна, а `*`, `/`, `+`, `-` левоассоциативны).
- **Разрешение неоднозначностей**: Токенизатор автоматически различает оператор остатка от деления (`10 % 3`) и постфиксный процент (`50%`), а также определяет неявное умножение без пробелов (`2x`, `3(a+b)`).
- **Кроссплатформенность**: Проект не использует внешних C-библиотек (чистый Lua), работает на Lua 5.3+, Lua 5.4, Lua 5.5 и LuaJIT на Windows, Linux и macOS.
